# signals-generator-app
Приложение WPF

## Назначение и состав
Репозиторий содержит настольное приложение WPF для работы с сигналами (построение графиков, наложение фильтров, анализ, сохранение и загрузка файлов). Проект включает только код окна, элементы управления и визуализацию, а предметная логика вынесена во внешнюю библиотеку.

Состав репозитория:
- `SignalGenerator.sln` — файл решения;
- `SignalGenerator.App` — проект приложения WPF (WPF App).

## Требования
- Целевая платформа: **.NET Framework 4.8**
- NuGet-пакет: **ScottPlot.WPF** версии `5.1.59`

## Связанные репозитории
