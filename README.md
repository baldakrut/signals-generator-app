# signals-generator-app
Приложение WPF

## Назначение и состав
Репозиторий содержит настольное приложение WPF для работы с сигналами (построение графиков, наложение фильтров, анализ, сохранение и загрузка файлов). Проект включает только код окна, элементы управления и визуализацию, а предметная логика вынесена во внешнюю библиотеку.

Состав репозитория:
- `SignalGenerator.sln` — файл решения;
- `SignalGenerator.App` — проект приложения WPF (WPF App).

## Требования
- Целевая платформа: **.NET Framework 4.8**
- NuGet-пакет: **ScottPlot.WPF** версии `5.1.59`

## Анализ пересечений порога (паттерн Observer)

В библиотеке `SignalProcessing.Core` реализован поиск пересечений заданного порогового значения (`ThresholdAnalyzer`):
- **Пересечение вверх (`CrossingDirection.Up`)** — переход от значения строго ниже порога к значению не ниже порога.
- **Пересечение вниз (`CrossingDirection.Down`)** — обратный переход.
- При обнаружении каждого пересечения анализатор генерирует событие `MarkerDetected` (`MarkerDetectedEventArgs` содержит сигнал, маркер, время в секундах и значение отсчёта), а по завершении возвращает неизменяемый `SignalAnalysisResult`.

В приложении `SignalGenerator.App` на событие подписаны два независимых обработчика окна: отображение цветных меток на графике через `SignalMarkerRenderer` (зелёные — вверх, красные — вниз) и вывод списка пересечений в `ListBox`. Повторный анализ или любое изменение набора кривых автоматически очищает прежнюю разметку.
